# Algorithme_genetique_TSP

Ce projet a été réalisé au cours de ma dernière année de licence Double Diplôme Droit Informatique en trinôme avec Ameylia Clement et Elisabeth Salame. 
Ce projet est l'implémentation d'un algorithme génétique pour répondre au problème du voyageur de commerce (Travelling Salesman Problem) en langage python. 

Pour exécuter le code source, il est préférable d'utiliser l'éditeur Jupyter Notebook.
